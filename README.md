## 📖 О проекте

Этот проект — моя индивидуальная работа по дисциплине **«Математика в профессиональной деятельности»** (Вариант 2/7). 

**Цель проекта:** наглядно продемонстрировать, как законы аналитической геометрии применяются в реальной жизни — в данном случае для расчёта безопасной траектории движения дрона-курьера на автоматизированном складе.

В проекте решается задача по поиску безопасного маршрута: дрон должен долететь из точки старта в точку финиша, не задев препятствие (опасную зону). Все вычисления сопровождаются подробными шагами, формулами и графической визуализацией.

## ✨ Особенности реализации

Помимо математических расчётов, проект представляет собой современное веб-приложение со следующим функционалом:

*   🌗 **Две темы оформления**: Светлая и тёмная тема с плавным переключением (реализовано на CSS-переменных).
*   📄 **Экспорт в PDF**: Встроенная функция печати, адаптированная под сохранение страницы в аккуратный PDF-документ (скрывает лишние элементы интерфейса при печати).
*   🧮 **Красивые формулы**: Все математические выражения отрендерены с помощью библиотеки **MathJax**.
*   📊 **SVG-графика**: Координатная плоскость, точки и векторы нарисованы с помощью встроенного SVG, который адаптируется под ширину экрана и меняет цвета в зависимости от темы.
*   📱 **Адаптивный дизайн**: Удобное чтение с любого устройства (от смартфона до ПК).
*   📑 **Навигация**: Боковое меню (TOC) с плавным скроллом к нужному разделу.

## 🧮 Суть математической задачи

В проекте решаются следующие задачи аналитической геометрии:
1.  **Координатная модель**: Заданы точки старта \(A(-2; -1)\), финиша \(B(4; 3)\) и препятствия \(C(2; 5)\).
2.  **Уравнение прямой**: Составлено уравнение маршрута дрона через две точки (\(2x - 3y + 1 = 0\)).
3.  **Вычисление расстояний**:
    *   Найдена длина маршрута дрона (модуль вектора \(\vec{AB} \approx 7.21\)).
    *   Вычислено кратчайшее расстояние от препятствия до маршрута (по формуле расстояния от точки до прямой).
4.  **Угол между направлениями**: Найден угол между вектором движения и вектором на препятствие.
5.  **Графическая модель**: Построены векторы и точка препятствия на плоскости.

## 🛠️ Стек технологий

*   **HTML5** — семантическая структура документа.
*   **CSS3** — кастомные свойства (CSS Variables), Grid, Flexbox, медиа-запросы (включая `@media print`).
*   **JavaScript (Vanilla)** — логика переключения тем и вызова окна печати.
*   **MathJax** — рендеринг формул LaTeX в HTML.
